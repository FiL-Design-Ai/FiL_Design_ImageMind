// Node Pack

Available Nodes

Node Category Purpose
🔌 Provider LoaderFiLProviderLoader LLM Choose provider, model, and generation parameters
🕵️ Optic ScannerFiLOpticScanner LLM Analyze images or expand text into a model-tuned prompt
💬 Prompt DirectorFiLPromptDirector LLM Tell the LLM how to rewrite an existing prompt: style transfer, re-lighting, medium change
📝 PrompterFiLPrompter LLM Smart text node with three live assist buttons (rephrase / densify / expand)
👁️‍🗨️ Image DecomposerFiLImageDecomposer Analysis Split an image or prompt into subject, lighting, composition, style
🎛️ Style MixerFiLStyleMixer Styling Blend styles and reference images with weighted influence
🎬 Cinema RigFiLCinemaRig Styling Build a cinematic shot from camera, lens, focal length, aperture and grade
⚡ KSamplerFiLKSampler Sampling Full sampler with passthrough sockets, preview and scripts
🔬 HighRes FixFiLHighResFix Sampling Latent/pixel upscale + re-sample script for KSampler
🎛️ Noise ControlFiLNoiseControl Sampling RNG source and seed-variation script for KSampler
🔍 Upscaler AdvancedFiLUpscaleTileCalc Image Tile layout, overlap and denoise planning for tiled upscale
🔍 Upscaler SimpleFiLUpscaleSimple Image Same tiling panel — model upscale in, image and tiles out
🧩 Tile AssemblyFiLTileAssembly Image Feather processed tiles back into one full-resolution image
🎨 Color WizardFiLColorWizard Image Auto colour correction — white balance, LAB contrast, stretch
📚 LoRA Dataset ForgeFiLDatasetForge Dataset Bucket a batch, caption it with an LLM, write a kohya/flat LoRA dataset
♻️ SeedFiLSeed Values Fixed or randomized seed with reuse buttons
🧹 CleanerFiLNeuroCleaner Tools Selective VRAM and model-cache cleanup
🔀 Cyber SwitchFiLSignalSwitch Tools Any-type pass-through gate — mute a branch without rewiring
📡 ChannelFiLChannel Tools Send data across the graph without wires
🔄 Model CyclerFiLModelCycler Tools Automatic diffusion model and checkpoint switcher
🧬 LoRA LoaderFiLLoraLoader Tools Automatic LoRA adapter cycler and inline weight parser
👁️ Show AnyFiLShowAny Tools Universal data inspector & pass-through monitor with live stats and 1-click copy
🎯 Edit EncoderFiLEditEncoder Conditioning Prompt + reference images in one conditioning for FLUX.2-family edit models
