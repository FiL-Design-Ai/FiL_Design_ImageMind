## Ловушки, на которых я уже спотыкался

Не повторять — каждая оплачена временем.

1. **Не выводить форму ноды из схемы. Спрашивать хост.** Я восстановил список виджетов для примеров
   воркфлоу из `GET_SCHEMA()` и написал тест, сверяющий файлы с той же схемой. Оба прошли — и оба
   были неверны. Живой хост отдаёт у Сканера 15 виджетов, а не 17; `width`/`height` — сокеты
   (`force_input=True`); многострочные поля идут в конце; после сида хост вставляет
   `control_after_generate`; последним элементом `widgets_values` лежит объект состояния Vue-панели.
   Питон — гонять через `tests/executor_harness.py`, фронт — через `frontend/tests/fakes/comfyHost.ts`.

2. **Тест, который не падает на возвращённом баге, — не защита.** Каждый новый тест проверять так:
   вернуть баг, убедиться, что тест покраснел, откатить. Я так поймал, что четыре из моих тестов
   действительно стерегут, а не украшают.

3. **Экспорт графа из живой ComfyUI тащит окружение.** Имя файла из папки `input`, локальные
   `provider`/`model`, `ue_properties` от `cg-use-everywhere`, `cnr_id`/`ver` с хешем коммита. В
   публичный репозиторий такое нельзя — вычищать.

4. **Русский текст в консоли Windows превращается в кракозябры.** Это cp1251 терминала, а не
   поломка файла. В своих скриптах — `sys.stdout.reconfigure(encoding="utf-8")`.

5. **Перед живой проверкой — отдельный пустой воркфлоу.** Открытый может жить только в localStorage
   браузера, и добавление ноды его перезапишет.

## Задачи по порядку

### 1. Примеры воркфлоу — СДЕЛАНО (коммит 275f5a2)

Перегенерированы из живой ComfyUI 1.47.10, утечки окружения вычищены, проверены загрузкой обратно.
Оба теста переписаны так, чтобы утверждать только то, что питон может знать: состав виджетов, но не
их порядок — порядок задаёт хост. `xfail` снят.

### 2. Компоненты нод без своих тестов — СДЕЛАНО (коммит 4f278d5)

Все шесть закрыты: `datasetForge`, `hiResFix`, `providerModelPicker`, `switch`, `upscaleTileCalc`,
`helpPopup` — свои файлы в `frontend/tests/components/`. Фронт вырос со 178 тестов до 270.

Написание тестов нашло настоящий дефект в 🔀 Cyber Switch: сторож в `watch` сравнивал
`nodeState.enable` сам с собой, поэтому тело никогда не выполнялось и внешняя запись (загрузка
воркфлоу, undo) не доезжала до нативного виджета, который читает бэкенд. Починено там же.

### 3. Облачные провайдеры — почти закрыто (2026-07-30)

Картинку реально увидели и описали **четверо**: `google`, `groq`, а на повторном прогоне ещё
`openrouter` (лимит отпустил, цепочка запасных моделей дошла до второго кандидата) и `cloudflare`.

Остался один: **openai** — у аккаунта нет квоты (`quota_exhausted`). Это не дефект пака и кодом не
чинится, нужен баланс. Повторить после пополнения:

```bash
E:\AI\ComfyUI-Easy-Install\python_embeded\python.exe tools\live_provider_check.py --provider openai --errors
```

Попутно на этом прогоне нашёлся и починен настоящий дефект — пустой баланс выдавался за «подожди
минуту», см. `audit.md`, 2.2. Проверка провайдеров, таким образом, окупилась не только галочками.

Локальные `ollama` и `lmstudio` по-прежнему не проверялись — не запущены, каталог моделей пуст,
выбирать vision-модель не из чего. Понадобится поднять хотя бы один.

### 4. Решения автора — ПОЛУЧЕНЫ И ВЫПОЛНЕНЫ (2026-07-30)

Все четыре закрыты. Подробности и обоснования — в `audit.md`.

| Вопрос | Решение | Чем закрыто |
|---|---|---|
| Контроль качества кода | включить только полезное | ruff + bandit включены и зелёные, форматировщики и мёртвый `.flake8` убраны, mypy оставлен вне гейта с записанной причиной, CI-работа `lint-python` |
| Трёхзначный hex | починить | `#f00` принимается; `#ff00`, `#f`, семь знаков — по-прежнему отвергаются |
| `config.yaml` | положить образец | `config.example.yaml` поставляется, README поправлен в обеих половинах, два теста стерегут наличие и отсутствие ключей |
| Кэш vision | выкинуть | Кэш убран; единственный факт, который он реально менял (`gemma-3n` не видит картинок), переехал в `OPENROUTER_EXCLUDED_MODEL_IDS` под тестом |

Две находки, всплывшие по ходу и стоящие больше самой уборки:

- **bandit нашёл шесть `md5`/`sha1` без `usedforsecurity=False`.** Все шесть — отпечатки для кэша, не
  безопасность, но без этой пометки вызовы **падают** на системе с FIPS. Убрана скрытая поломка.
- **У пака не было своего ruff-конфига**, поэтому ruff изнутри ComfyUI брал правила ComfyUI, а в CI —
  правила по умолчанию: один код, два вердикта. Теперь правила свои.
